# Smart Booking 機能追加仕様書（空き状況表示のカスタマイズ）

## ドキュメント情報

| 項目 | 内容 |
|------|------|
| 対象バージョン | v0.5.1 |
| ステータス | 仕様確定（2026-07-17 合意） |
| 背景 | 外部ユーザー要望「現在2件で『残りわずか』になるが、1件で表示したい」。汎用化の観点からしきい値・文言・色を設定可能にする |
| 前提 | v0.5.0 リリース済み |
| 設計原則 | YAGNI / シンプルさ優先 / 3原則（壊さない・デグレさせない・影響範囲を調査する） |

## 概要

予約フォームの時間枠の空き状況表示（残りわずか / 満席 / 締切）について、以下3点を管理者が設定できるようにする。

1. **しきい値**: 残り何件以下で「残りわずか」にするか
2. **文言**: 「残りわずか」「満席」「締切」の表示テキスト
3. **色**: 「残りわずか（警告色）」「満席・締切（無効色）」の表示色

**初期値はすべて現行挙動と同一 = 既存ユーザーの表示は1文字・1色も変わらない**（デグレなし）。

## 仕様

### 1. しきい値設定（v0.5.1 実装時に確定・2026-07-29）

> ⚠️ **当初案の誤記訂正**: 当初の仕様は「現行の内部固定値＝3」「残り3件以下」を前提にしていたが、実装前調査で現行判定は**単純な固定値ではなく複合式**であることが判明した。以下は事実に基づく確定仕様。

| 項目 | 内容 |
|------|------|
| 設定場所 | 設定 > 基本設定タブ |
| 設定項目 | 「残りわずかのしきい値」（数値入力・**空欄可**） |
| 現行挙動（正） | サーバー側 `class-rest-public.php::get_availability()` の**2箇所**（通常モード／担当者統合モード）にある複合式：`空き数（capacity - booked_count）<= 2 または 空き数 <= ceil(capacity * 0.3)`（＝**絶対値2席 または 残席30%以下**）。 |
| 意味（数値設定時） | **1〜99 の整数を設定した場合**、空き数がその値**以下**のとき「残りわずか」表示（フラット判定 `空き <= しきい値`）。このとき現行の複合式は無効化される。 |
| デフォルト（未設定＝空欄） | **現行の複合式を厳密に維持**（`空き<=2 または 空き<=ceil(capacity*0.3)`）。既存ユーザーの表示は**1枠も変わらない**（デグレ最重要の担保）。 |
| 不正値の扱い | **0・負数・空・文字列等の不正値は「未設定（＝自動・複合式）」にフォールバック**。（当初案「不正値→デフォルト3」は、現行が固定3ではなく複合式だったため「不正値→未設定（自動）」に読み替える。） |
| 保存先 | 個別 option `smart_booking_few_left_threshold`（既存の設定 whitelist 方式。①呼び方設定と同型）。 |
| 判定の集約 | しきい値の読み取り＋有効値判定（1〜99なら整数／それ以外は null＝自動）は**共通ヘルパー1箇所**に集約し、`get_availability()` の2箇所と `/public/settings` の両方から使う。 |
| 設定UIの表現 | 数値入力は空欄可、プレースホルダ「自動」。説明文＝「空欄の場合は自動判定（空き2件以下、または定員の30%以下で『残りわずか』）。数値を設定すると、空きがその数以下のときだけ表示されます。例: 1 にすると残り1件のときのみ」の趣旨。 |

### 2. 文言設定

| 項目 | 内容 |
|------|------|
| 設定場所 | 設定 > 基本設定タブ（しきい値の近傍にまとめる） |
| 設定項目 | 「残りわずかの表示」「満席の表示」「締切の表示」（テキスト入力 ×3） |
| デフォルト | 残りわずか / 満席 / 締切（現行文言と同一） |
| 空文字時 | デフォルトにフォールバック（①呼び方設定と同じ原則） |
| 文字数上限 | 20文字（呼び方設定と同一） |
| 保存先 | 個別 option ×3（同上） |
| 反映箇所 | フロント予約フォームの時間枠表示（バッジ/ラベル）、および同文言を使う aria-label 等のアクセシビリティ属性 |
| 管理画面 | 変更しない（管理画面の表記は固定。①と同じ判断: サポート・ドキュメントとの表記整合を守る） |

### 3. 色設定

| 項目 | 内容 |
|------|------|
| 設定場所 | 設定 > デザインタブ（既存カラーカスタマイズに追加） |
| 設定項目 | 「残りわずかの色（警告色）」「満席・締切の色（無効色）」 |
| デフォルト | 現行の警告色 / 無効色と同一値（実装時に現行 CSS から正確な値を採取して初期値とする） |
| 実装方式 | 既存の CSS カスタムプロパティ出力に変数を追加（新しい仕組みは作らない） |
| 適用範囲 | 「残りわずか」= バッジと時間枠ボタンの警告表示。「満席・締切」= グレーアウト表示（2状態で1色を共有。満席と締切を別色にはしない） |
| 注意書き | 既存のデザインタブと同様、コントラスト比はユーザー責任の注意書きに含める |

### フロントへの受け渡し

| 項目 | 内容 |
|------|------|
| エンドポイント | 既存の `GET /public/settings` にキーを追加（しきい値1・文言3・色2） |
| フォールバック判定 | サーバー側（レスポンス生成時）で行い、フロントは受け取った値をそのまま使う（①で確立した「判定ロジック1箇所集約」の原則） |

## データ設計

| 項目 | 内容 |
|------|------|
| DB変更 | **なし**（option 追加のみ。マイグレーション不要） |
| option | しきい値1・文言3・色2 の計6キー（既存の命名規則 `smart_booking_*` に従い、実装時に既存 whitelist の流儀で命名） |

## 完了条件

- しきい値を 1 に設定すると、残り1件の枠だけ「残りわずか」表示になる（残り2件は通常表示）
- しきい値が**未設定（空欄）のとき、現行の複合式（空き2件以下 または 定員の30%以下）と完全に同一挙動**（全 capacity で1枠も変わらない）
- 文言3種を変更するとフロントの該当表示・aria-label に反映される。空文字はデフォルト表示
- 色2種を変更するとフロントの該当表示色が変わる
- **全設定が初期値（＝しきい値未設定・文言/色未設定）のとき、フロントの表示（文言・色・しきい値挙動）が v0.5.0 と完全に同一**（デグレ最重要）
- 管理画面の表記・配色が変わらないこと
- 不正値がサーバー側で弾かれる：**しきい値 0/負数/文字列は「未設定（自動＝複合式）」にフォールバック**、**色の不正カラーコードはデフォルト色にフォールバック**

## 不採用・保留事項（判断記録）

| 項目 | 判定 | 理由 |
|------|------|------|
| ○▲×アイコン表示モード | 🔵 保留 | 「値の設定化」ではなく新しい表示モードの追加であり、UI設計からやり直しになる。実要望がまだ無く YAGNI。実要望が来た時点で表示デザイン案から議論する（カスタマイズ案件の候補でもある） |
| 満席と締切の色を別々に設定 | ❌ 不採用 | どちらも「選択不可」の意味で、色を分けると誤解を招く。設定項目も増える |
| しきい値のフォーム別・店舗別設定 | ❌ 不採用 | 組み合わせ爆発。グローバル1つで十分。必要ならカスタマイズ案件 |
| 「通常（空きあり）」の文言設定 | ❌ 不採用 | 通常時は文言バッジ自体が無い（色のみ）ため対象外。通常色は既存デザイン設定に既にある |
